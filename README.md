# StudyDeck — CLI flashcards with SM-2 spaced repetition

A dependency-free .NET 8 CLI for studying with flashcards that actually
schedule themselves: every review updates the card with the classic SM-2
algorithm, so easy cards drift weeks apart and hard cards come back tomorrow.

> Work in progress in this commit: core domain model + SM-2 scheduler.
> The CLI, persistence, review sessions, stats and import/export land in
